# Pak-Prep implementation roadmap

## Foundation (committed)
- Expo React Native app shell and nationwide BPS-5–22 recruitment directory.
- Job-family and subject catalogues.
- Sample original practice questions, clearly separate from official past papers.
- Supabase relational schema with row-level security.
- Local progress/bookmark storage module.
- CSV import template and structural validation script.
- Store listing and privacy policy drafts.

## Next implementation milestones
1. Configure Supabase project URL and public anon key; run migrations.
2. Build authenticated admin dashboard and import/review queue.
3. Collect authorized papers from federal, provincial, AJK and GB bodies.
4. Add searchable paper detail, PDF viewer, answer keys and explanations.
5. Add timed quizzes, bookmarks, history and progress screens.
6. Complete Dawn article catalogue and independently verified vocabulary.
7. Add offline downloads, accessibility, localization and device QA.
8. Complete signed Android APK/AAB and iOS IPA builds and store submissions.

## Coverage definition
BPS-5 through BPS-22 across Federal, Punjab, Sindh, Khyber Pakhtunkhwa, Balochistan, AJK and Gilgit-Baltistan. Each post is a distinct record; job-family labels are navigation only, not a substitute for individual post/paper records.
