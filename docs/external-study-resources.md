## Rights and provenance rules

1. Do not bulk-copy, scrape, mirror, rehost, or redistribute third-party MCQ banks, notes, articles, videos, answer explanations, or PDF files without a documented licence or written permission from the rights holder.
2. Publicly accessible does not automatically mean public domain or freely reusable.
3. Link to the source page when permission to reproduce is absent.
4. Import only content with a recorded rights basis (for example, CC licence, public-domain status, or written authorization).
5. Keep the source URL, source title, author/owner where known, licence/permission evidence, import date, reviewer, and verification status with each imported item.
6. Clearly distinguish official past-paper questions from original Pak-Prep practice questions and third-party links.
7. Where permission is not available, create independently written practice questions aligned to the publicly described syllabus. Do not paraphrase or reconstruct a proprietary question bank.

## Suggested import metadata

For each authorized MCQ: subject, topic, question, four options, correct option, explanation, language, difficulty, source URL, rights basis, rights evidence, reviewer, and publication status.

For each authorized past paper: recruiting body, post/job title, BPS, year, subject/paper name, language, original source URL, rights basis, rights evidence, and verification status.
